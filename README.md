# Мир после…

Роман Дана Влива. Основной канон и тексты глав хранятся в `chapters/`.

## Публикация
- GitHub Actions workflow: `.github/workflows/publish.yml`
- Автоматическая публикация: понедельник–суббота, 09:00 по Владивостоку (UTC+10).
- Очередь публикаций: `posts/queue/YYYY-MM-DD.txt`.
- Обложка к дате публикации (если есть): `posts/covers/YYYY-MM-DD.jpg`.
- Ручной запуск использует `posts/next.txt`; необязательная обложка — `posts/next.jpg`.
- Если обложка найдена, Telegram получает сначала изображение, затем полный текст главы отдельным сообщением. Если изображения нет, отправляется только текст.
- Для отправки нужны GitHub Secrets `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHANNEL_ID`.

Расписание публикует только заранее подготовленные тексты. Оно не генерирует новые главы автоматически: новые главы и обложки нужно подготовить и добавить в репозиторий заранее.
