# Мир после…

Роман Дана Влива. Основной канон и тексты глав хранятся в `chapters/`.

## Публикация
- GitHub Actions workflow: `.github/workflows/publish.yml`
- Автоматическая публикация: понедельник–суббота, 09:00 по Владивостоку (UTC+10).
- Очередь публикаций: `posts/queue/YYYY-MM-DD.txt`.
- Ручной запуск использует `posts/next.txt`.
- Для отправки нужны GitHub Secrets `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHANNEL_ID`.

Расписание публикует только заранее подготовленные тексты. Оно не генерирует новые главы и пока отправляет текстовые сообщения, не обложки. Обложки создаются отдельно и должны быть добавлены в репозиторий и workflow, прежде чем их можно будет публиковать автоматически.

## Канон
- Вступление: `chapters/introduction.md`
- Главы 1–9: `chapters/chapter-01.md` … `chapters/chapter-09.md`
- Главный герой пока остаётся безымянным; его имя и прошлое раскрываются постепенно.
